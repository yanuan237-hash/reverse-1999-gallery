# 重返未来 1999 · 图画集下载器（图形界面版）

双击即用的桌面工具：浏览官网图画集 → 勾选下载 → 本地画廊查看。
**不需要安装任何依赖**（不需要 Flutter、不需要 npm install），只要有 Node.js。

---

## 快速开始

**双击项目根目录的 `启动.bat`**（就在 `1999\` 下，不在这个文件夹里）。
如果中文文件名不好使，就双击旁边的 `start.bat`——两个内容一样，后者只是 ASCII 文件名。

它会做四件事：

1. 检查 Node.js 是否已安装
2. 检查端口是否已被占用（避免重复开）
3. 启动本地服务（只监听 `127.0.0.1`，不对外网开放）
4. 用 Edge / Chrome 的 **应用模式** 打开界面（没有地址栏，看起来就是个独立程序）

窗口里会显示启动进度；**保持这个窗口开着**即可，用完关掉窗口就停止服务。

> 前提：已安装 Node.js 18 或更高版本（<https://nodejs.org/>）。

### 启动不了？先自检

在项目根目录打开命令行（或在目录空白处按住 Shift 右键 →「在此处打开 PowerShell」）运行：

```
启动.bat --test
```

它会逐项检查 Node、端口、浏览器，然后真正拉起服务、请求首页和图集接口，最后打印服务日志。
**把这段输出发给我就能定位问题。** 正常应看到：

```
[1/4] Node.js v24.21.0  OK
[2/4] Port 19990 is free
[3/4] Browser: "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
   Page : HTTP 200, 28175 bytes
   API  : 1001 wallpapers from official site
```

### 想换端口

默认 19990。先设环境变量再运行：

```
set PORT=20000
启动.bat
```


### 三个页面

| 页面 | 作用 |
| --- | --- |
| **官网图集** | 从 re.bluepoch.com 拉取全部 1001 张图画集，带缩略图；按名称/编号/分辨率搜索，按发布日期筛选，横竖版切换；点卡片多选，右下角「下载选中」开始下载 |
| **本地画廊** | 浏览已下载的图片，同样的搜索/日期/横竖版筛选，点图看大图 |
| **设置** | 保存目录、并发数、缩略图尺寸与质量、HTTP 代理 |

下载时底部出现进度条：百分比、已下载体积、速度，以及逐条日志（`✓` 新增 / `·` 已存在 / `✗` 失败）。

### 断点续传

已下载的文件会自动跳过。中途关掉窗口、断网都没关系，**再次点「下载选中」即可续传**，不会重复下载。

## 技术说明

### 缩略图是自己算的（零依赖）

官网那 1001 张原图合计约 2 GB。如果界面直接用原图，滚动一次就要下几十 MB。
所以程序在服务端**按需生成缩略图**（480px、约 15 KB），并缓存到 `data/thumb-cache/`。
生成用的是自己写的纯 JavaScript JPEG 引擎（`lib/jpeg.mjs`）：

- **解码**：只取每个 8×8 数据块的 DC 系数（它就是该块的平均色），
  完全跳过 IDCT —— 速度约为完整解码的数十倍（实测 1001 张平均 **71 ms/张**）。
  支持基线 JPEG、4:2:0 / 4:2:2 / 4:4:4 采样、以及带重启标记（RSTn）的码流。
- **编码**：标准霍夫曼表 + 4:4:4 基线 JPEG，带 JFIF APP0 头。

用到的几个容易踩的点（都已处理）：

| 坑 | 处理 |
| --- | --- |
| 图片 CDN 只接受 HTTP/2 | 用 Node 内置 `fetch`（undici）；Python/curl 直连会收到 `567` |
| 直链含中文与空格 | 逐段百分号编码 |
| 渐进式 JPEG 无法走 DC 快速路径 | 服务端返回 `204`，前端自动改用官网原图直链 |
| 官网标题的「横版/竖版」是错的 | 读取图片文件头拿真实宽高判定 |

### 接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/remote` | 官网图画集清单（含解析后的名称/分辨率/横竖版/日期） |
| `GET /api/thumb?u=<图片直链>` | 缩略图（磁盘缓存；渐进式返回 204） |
| `POST /api/download` | 开始下载（body 传 `items` 或 `filter`） |
| `GET /api/progress` | SSE 实时进度 |
| `GET /api/status` | 当前任务状态（JSON，SSE 的兜底） |
| `GET /api/library` | 本地已下载清单 |
| `GET /api/file?f=<相对路径>` | 读取本地图片（已做目录穿越防护） |
| `GET/POST /api/settings` | 读写设置 |
| `POST /api/thumb-clear` | 清空缩略图缓存 |
| `GET /api/collections` | 官网全部分类 |

## 常见问题

**Q：双击没反应 / 一闪而过 / 提示乱码？**
先跑 `启动.bat --test` 看输出。历史上有两个已知坑，都已修好：

- 启动脚本必须**纯 ASCII + CRLF** 保存。`cmd.exe` 用系统 OEM 代码页（中文 Windows 是 GBK）读 `.bat`，
  文件里若混入 UTF-8 中文，脚本自身会被解析成乱码而失效。
- `start` 命令里**不能出现嵌套引号**（如 `start "t" /min cmd /c "node "path""`），否则命令被截断，
  在含空格的路径（例如 `D:\AI perfect\`）下必然失败。

如果你自己改脚本，注意这两点。

**Q：提示「未检测到 Node.js」？**
去 <https://nodejs.org/> 装 LTS 版本，装完**重开一次命令行/资源管理器**再试。

**Q：提示端口被占用？**
说明已经有一个实例在跑（或别的程序占了 19990）。直接用浏览器打开
<http://127.0.0.1:19990/> 即可；或换端口：`set PORT=20000` 后重新运行。

**Q：界面打开了但缩略图一直转圈？**
缩略图是现算的，第一张会慢一点（几十到一百多毫秒），之后走缓存就很快。
官网 CDN 偶发限速，多等一会儿或重新加载。

**Q：想换保存位置？**
在「设置」里改保存目录，点保存。图片会写到 `<保存目录>\wallpapers\`。

**Q：代理怎么配？**
在「设置」里填 `http://127.0.0.1:7890` 这类地址，保存后**重启应用**生效。

**Q：服务怎么彻底关掉？**
关掉那个显示「Service : http://127.0.0.1:19990/」的命令行窗口即可。
若已丢失窗口，在任务管理器结束 `node.exe`。

**Q：会不会把我已有的 1001 张图重新下一遍？**
不会。默认保存目录就是项目根下的 `1999-wallpapers`，已下载的文件会自动跳过。
